# Personal Blog

This project is a personal blog built using Next.js and MongoDB.

## Features

- Next.js frontend
- MongoDB database connection
- API route for fetching blog posts
- Sample blog posts displayed dynamically
- Styled blog homepage

## Technologies Used

- Next.js
- MongoDB Atlas
- Tailwind CSS
- Node.js

## How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/Suhurrith-Adhikari/PersonalBlog.git
```

2. Navigate into the project folder:

```bash
cd personal-blog
```

3. Install dependencies:

```bash
npm install
```

4. Create a `.env.local` file and add:

```env
MONGODB_URI=your_mongodb_connection_string
```

5. Start the development server:

```bash
npm run dev
```

6. Open in browser:

```text
http://localhost:3000
```
